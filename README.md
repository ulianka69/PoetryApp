# 📚 PoetryApp
Приложение для чтения и хранения стихов с облачной базой данных.

## ✨ Возможности
- 🔐 Вход и регистрация через Firebase Auth
- 📖 Просмотр стихов с красивым оформлением
- 🔍 Мгновенный поиск по автору и названию
- ⭐ Добавление в избранное (синхронизация с Firestore)
- ➕ Добавление новых стихов прямо из приложения

## 🛠 Стек технологий
- Java, Android SDK
- Firebase Authentication + Cloud Firestore
- Material Design 3, RecyclerView
- MVVM архитектура

## 🚀 Как запустить
1. Клонируй репозиторий: `git clone https://github.com/ТВОЙ_НИК/PoetryApp.git`
2. Открой в Android Studio
3. Подключи свой `google-services.json` из Firebase Console
4. Запусти на эмуляторе или устройстве
